# このファイルは「1条件分」のステップのみを記述します。

# 10条件を参加者ごとに異なる順序で展開します。

# 10条件:
#   A: IR × Ray          F: Webcam × Frustum
#   B: IR × Circle       G: WebcamFiltered × Ray
#   C: IR × Frustum      H: WebcamFiltered × Circle
#   D: Webcam × Ray      I: WebcamFiltered × Frustum
#   E: Webcam × Circle   J: NoGaze
#
# 各条件の実行フロー（ExperimentManagerが制御）:
#   WhiteNoise → Session開始(OSC) → Task1(識別) → Task2(組み立て+配置) → アンケート → 休憩
#
# 利用可能な Step types:
#   noise         — ホワイトノイズ（自動終了）
#   task          — 識別課題（taskDurationSeconds）
#   assembly      — 組み立て+配置指示課題（assemblyDurationSeconds, video feed ON）
#   alignment     — 位置合わせゲート（video feed ON, Enterで進む）
#   questionnaire — ゲート（Enterで進む / アンケート完了で自動進行）
#
# 各ステップには [remote] と [local] ブロックで
# Remote Expert と Local Worker それぞれへの指示を書きます。
# どちらかを省略した場合、そのロールには何も表示されません。
#
# ステップの区切りは ===
# # で始まる行と空行は無視されます
